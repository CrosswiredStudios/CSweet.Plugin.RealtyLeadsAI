# 0.2.1

Three optional output fields on both reviewed reads, for the Lead Research Analyst's table.

- `dateOfDeath` (ISO 8601 string, max 32), `totalHeirs` and `contactableHeirs` (integers 0–1000)
  are added to the `realtyleads.inheritance.search.v1` and `realtyleads.inheritance.lookup.v1`
  output schemas as optional properties. Schemas stay closed; the host rejects anything else.
- Counts only: no heir names, phones or addresses leave the provider.
- Roll out this plugin version before the RealtyLeads MCP server starts returning the fields;
  until the server does, consumers see the fields absent.
- No input, endpoint, authentication or tool-mapping changes.
