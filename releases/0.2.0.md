# 0.2.0

Moves to the publisher-neutral reviewed remote MCP mode (SDK 5.8.0, protocol 2.6).
The endpoint, header and capability-to-tool mapping now live in this manifest
(`reviewedRemoteMcp.tools`) instead of C-Sweet host code. Output string fields
declare explicit `maxLength` bounds. Capabilities, schemas' field sets and the
read-only scope are unchanged from 0.1.0.

Requires a C-Sweet host with the generic remote MCP broker. 0.1.0 (protocol 2.5)
is rejected by that host; reinstall 0.2.0 and grant access again.
